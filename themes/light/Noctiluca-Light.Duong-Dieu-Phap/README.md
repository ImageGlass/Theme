# Noctiluca Light

Noctiluca Light is a warm, light theme with cream backgrounds and rounded icons in green, blue, terracotta, and gold. The toolbar, gallery, and menus use slightly different shades of cream to keep the layout clear. Its custom "ig" logo follows the same colors.

## Install in ImageGlass 10

1. Open Settings (Ctrl+,), then Appearance → Theme.
2. Click Install theme packs and choose the .igtheme.zip file.
3. Assign this pack to Light mode.
4. Click Apply or OK. Use the matching app color mode to see the theme.

## Design

- Fixed accent: #237A68; viewer: #F6F2E9; text: #343B37.
- 35 original, self-contained SVG toolbar icons on a 24 × 24 grid.
- Soft enamel fills, rounded joins and smooth jade navigation arrows.
- A clear lowercase ig monogram in terracotta and jade with a saffron sun dot.
- Opaque surfaces keep the palette consistent across Windows backdrops.
- preview.svg is the editable source for the included 1200 × 760 WebP preview.
- Original SVG artwork; no third-party icon libraries or external assets.

## Notes

A custom viewer background in your app settings may override the theme background.
Use the theme background for the intended palette.
