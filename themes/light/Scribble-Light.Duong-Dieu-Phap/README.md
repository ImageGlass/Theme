# Scribble Light

Scribble Light uses black ink on cool white paper, with cherry-red pencil marks and touches of violet. The icons have uneven contours, loose shading, and a few hatch marks, like drawings in the margin of a notebook. Its handwritten "ig" logo sits on a dark ink tile, with a red dot to match the controls.

Author: Duong Dieu Phap

## Install in ImageGlass 10

1. Open Settings (Ctrl+,), then Appearance → Theme.
2. Click Install theme packs and select the .igtheme.zip file.
3. Select Scribble Light for Light mode, then click Apply or OK.
4. Use the matching app color mode to see the theme.

## Artwork

- 35 original SVG toolbar drawings on a 24 × 24 grid, with rounded joins and caps.
- Uneven pen contours, offset pencil-color fills and sparse hatch marks.
- A custom handwritten lowercase "ig" logo. Logo.svg fills its 128 × 128 viewBox with no outer padding.
- A 1200 × 760 WebP preview, with its editable SVG source.
- Self-contained artwork: no icon fonts, linked images or third-party icon libraries.
