# Halide Light

Halide Light uses pale lavender surfaces with deep violet icons and small apricot details. The controls have broad, rounded shapes inspired by the dials and cutouts of film cameras. A matching "ig" logo and gently shaded toolbar, gallery, and menus carry the same colors throughout ImageGlass.

Author: Duong Dieu Phap

## Install in ImageGlass 10

1. Open Settings (Ctrl+,), then Appearance → Theme.
2. Click Install theme packs and select the .igtheme.zip file.
3. Select Halide Light for Light mode, then click Apply or OK.
4. Use the matching app color mode to see the theme.

## Artwork

- 35 original SVG toolbar icons on a 24 × 24 grid, with rounded joins and caps.
- A violet and apricot palette with broad silhouettes and small, clear details.
- A custom lowercase "ig" logo. Logo.svg fills its 128 × 128 viewBox with no outer padding.
- A 1200 × 760 WebP preview, with its editable SVG source.
- Self-contained artwork: no icon fonts, linked images or third-party icon libraries.
