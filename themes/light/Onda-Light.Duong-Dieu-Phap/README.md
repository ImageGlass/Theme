# Onda Light

Onda Light uses white and pale gray surfaces with a single slate-gray icon color. The icons are drawn with thin, rounded strokes and open shapes, with no extra shading or decoration. Its circular "ig" logo follows the same monochrome style, and the toolbar, gallery, and menus use subtle changes in gray.

Author: Duong Dieu Phap

## Install in ImageGlass 10

1. Open Settings (Ctrl+,), then Appearance → Theme.
2. Click Install theme packs and select the .igtheme.zip file.
3. Select Onda Light for Light mode, then click Apply or OK.
4. Use the matching app color mode to see the theme.

## Artwork

- 35 original SVG toolbar icons on a 24 × 24 grid, with rounded joins and caps.
- Exactly one visible color per icon, with consistent 1.8-unit strokes and rounded ends.
- A circular "ig" logo with transparent lettering, painted in the same single icon color. Logo.svg fills its 128 × 128 viewBox with no outer padding.
- A 1200 × 760 WebP preview, with its editable SVG source.
- Self-contained artwork: no icon fonts, linked images or third-party icon libraries.
